# Gary Wallage Industrial Performance Plugin

High-performance optimization engine for Gary Wallage Photography WordPress Multisite ecosystem. Consolidates bloat removal, LCP protection, Core Web Vitals optimization, and asset management into a zero-overhead plugin.

## Core Features
1. **WP Bloat Removal**: Disables emojis, embeds, XML-RPC, RSD links, manifest links, and unnecessary WP header junk.
2. **LCP & Image Optimization**: Intelligent lazy loading controls, high-priority preloading for Largest Contentful Paint candidates, and automatic modern WebP swapping.
3. **Script & Style Optimization**: Script deferral, query string stripping, and critical CSS prioritization.
4. **Heartbeat & Resource Throttling**: Restricts WordPress heartbeat API to minimize server CPU overhead.
5. **SEO & Schema Integration**: Zero-overhead JSON-LD schema injection, OpenGraph meta, breadcrumbs, and layout shift (CLS) prevention.
6. **Speculation Rules**: Chrome Speculation Rules pre-rendering for instant page transitions across the portfolio.
